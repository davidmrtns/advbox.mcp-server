# ADVBOX MCP Server

Remote Streamable HTTP MCP server for read-only ADVBOX API access.

## Development

Copy the environment template and adjust the values as needed:

```bash
cp .env.example .env
```

```bash
npm start
npm run inspect
```

The MCP endpoint is available at `http://127.0.0.1:3000/mcp` by default.

## Configuration

- `HOST`: HTTP bind address. Default: `127.0.0.1`. Use `0.0.0.0` in containers.
- `PORT`: HTTP port. Default: `3000`.
- `ALLOWED_HOSTS`: comma-separated hostnames accepted by the `Host` header. Default: `localhost,127.0.0.1,[::1]`.
- `ALLOWED_ORIGINS`: comma-separated origin hostnames accepted by the `Origin` header. Default: `localhost,127.0.0.1,[::1]`.
- `LOG_LEVEL`: structured log level: `debug`, `info`, `warn`, or `error`. Default: `info`.

Example for a container exposed through a public domain:

```bash
HOST=0.0.0.0 \
PORT=3000 \
ALLOWED_HOSTS=mcp.example.com \
ALLOWED_ORIGINS=mcp.example.com \
npm start
```

Browsers send an `Origin` header; non-browser MCP clients normally do not. For a proxy or public deployment, configure `ALLOWED_HOSTS` and `ALLOWED_ORIGINS` for the actual public hostnames instead of allowing all origins.

## Observability

- `/health/live`: liveness check; no Host or Origin validation is required.
- `/health/ready`: readiness check; no Host or Origin validation is required.
- Logs are emitted as JSON to stdout/stderr, including request ID, method, path, status and duration.
- Responses include `x-request-id`, which may be supplied by the caller or generated by the server.
- SIGTERM and SIGINT trigger graceful HTTP and MCP shutdown.

## ADVBOX tools

The server exposes read-only tools for account settings, contacts, lawsuits, movements, tasks, transactions and documents.

Set `ADVBOX_TOKEN` and optionally `ADVBOX_API_URL` in `.env`. Requests are limited to 30 per minute per server process and API responses are truncated above 150,000 characters.

## HTTP utilities and API services

The generic HTTP client lives in [`src/utils/http-client.ts`](/src/utils/http-client.ts):

```ts
import { HttpClient } from './utils/index.js';

const api = new HttpClient('https://api.example.com', {
  timeoutMs: 10_000,
  headers: { Authorization: 'Bearer token' },
});
```

API-specific endpoints belong in [`src/services/`](/src/services) and compose this client:

```ts
import { NotesService } from './services/index.js';

const notes = new NotesService(api);
await notes.list();
await notes.create({ text: 'hello' });
```
